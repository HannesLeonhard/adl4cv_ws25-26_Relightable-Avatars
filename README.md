# Relightable Avatars from Material-Aware Diffusion Models

## Setup Environment

### Setup rgbx

1. Add rgbx as submodule via `git submodule update --init --recursive`
2. Setup conda environment according to the instructions in `rgbx/`
3. Install current project so that it is available in notebooks with `pip install -e .`
4. For code quality install `conda install ruff`. Code can the be formatted with `ruff format .`

### Setup diffusion renderer

1. Add diffusion_rendere as submodule via `git submodule update --init --recursive`
2. Setup conda environment according to the instructions in `diffusion_renderer/`
3. Install current project so that it is availabel in notebooks with `pip install -e .`
4. For code quality install `conda install ruff`. Code can the be formatted with `ruff format .`
